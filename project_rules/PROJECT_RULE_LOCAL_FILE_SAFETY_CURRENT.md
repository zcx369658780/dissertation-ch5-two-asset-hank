## 保存和 manifest
每次科学运行分配新目录，原始产物优先落盘再计算附加诊断。
manifest 记录决定结论的源、输入、配置、输出、比较器和日志身份。缓存/编辑器临时文件不因位于同目录就成为科学验收条件。
manifest 不包含自身及其终端 readback receipt；不递归自哈希。产物完成后一次完整性核验足够，变化或损坏时才重验。
后处理失败且核心输出完整时使用原产物修复诊断，避免无必要模型重跑。
储存故障时先保存可用证据；任务已允许的输出目录修复可继续，模型重跑必须仍在明确预算内。

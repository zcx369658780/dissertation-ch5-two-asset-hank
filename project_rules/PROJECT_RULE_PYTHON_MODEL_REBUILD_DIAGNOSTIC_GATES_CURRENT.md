# Python 模型实现与诊断
更新：2026-09-07；替代旧 16 个小 gate 的强制逐项交接及 retry 必须新 task 的规定。

## 适用对象
Chapter 5 当前两资产模型；旧 one-asset R5 科学路线不再适用。当前忠实 MATLAB 重构的具体源/数值契约由 live task 与已接受报告指定；不能泛称所有旧 MATLAB 输出都是 oracle。

## 完整工作单元
一个任务可覆盖设计、范围内源码/测试修复、相关验证、明确预算的运行和报告。实现授权不等于无限运行；允许运行须在同一 task 中写清即可，不强制第二任务。
静态检查、数据读取、hash、保存数组比较与合成 IO 检查不计科学调用；真实 HJB/KFE/求解器调用按实际计数。

## 任务内修复
Builder 可修复已授权的工程故障并重试相关普通检查。模型重试的次数、允许原因、配置与资源上限预先写入 task；不得事后给已消费调用改名或重置预算。
不得用工程修复名义改变方程、边界、求解器语义、精度、参数或容差。
已有源身份和合格证据可引用。测试选取变更影响的行为和不变量，不为可逆文本更新运行全模型回归。

## 科学检查
- HJB：适用的残差、策略/边界、收敛状态。
- KFE：算子方向、质量、非负性和残差。
- 聚合/多省份：权重、方向、会计对象、更新次序与外层收敛。
- 动态：仅在有已冻结契约时验证时序、初末条件、冲击、路径和截断。
方法、容差、迭代上限及输入身份在观察结果前确定。

## 输出与论文
按证据保存规则保留失败和成功输出。一份 run manifest + 相关诊断 + 一份结果报告通常足够。
优化在受影响正确性有证据后进行；性能改动须验证数值行为未改变。
科学模块测试通过不自动证明全部模型、校准、政策效应或论文结论成立。

# 验收证据标签
更新：2026-09-07。

L0–L4 是描述实际证据的标签，不是依次升级的五道任务门禁，也不决定验收人必须使用某个模型。

| 标签 | 实际证据 | 可支持的结论 |
| --- | --- | --- |
| L0 | 聊天中的完成声明 | 执行者声称完成，尚未读取产物 |
| L1 | 已读取本地产物 | 对已读文件的内容判断；仅提供路径不等于读取 |
| L2 | 已读取 GitHub 文件 | 仓库文件内容支持的判断 |
| L3 | 核验 commit/PR 的相关 diff 与变更范围 | 对提交身份、范围及已读证据的验收 |
| L4 | 已读取相关测试/CI 日志或产物 | 测试证据支持对应行为；标明是否独立运行 |

按任务风险选择足够的证据，不为获得更高标签重复运行。
报告中简述证据、结论和真实限制；不必逐项重复所有空字段。
L3 不意味着访问过外部 Windows 文件；L4 不意味着经济模型或政策结论有效。
科学验收另需方程、同输入关系、残差/收敛、质量守恒等适用证据。已接受且未改变的证据可复用。

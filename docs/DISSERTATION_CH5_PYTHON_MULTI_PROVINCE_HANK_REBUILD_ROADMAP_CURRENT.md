## 不变量
- 生产资本使用 At*N，不能替换为 At+Bt；Bt 保持液体资产含义。
- household Lt 与迁移后的 firm Lt_supply 分开。
- 保留来源规定的省份排序、矩阵方向与旧状态共同输入。
- 当前 source-faithful 外层 update map 不悄改为新的 root solver。
- 保护 MATLAB 源不变；同输入、容差和科学预算都可追溯。
- MATLAB 名为 IRF 的顺序比较静态路径不自动等于 backward-HJB/forward-KFE 动态系统。

# Payload privacy report

Only the authorized HJB change, one new AST test and this task's evidence are published. No credentials, private Excel, protected assets, disk listings or raw private workspace paths are included. No protected scientific tree, WASM, reparse target, old locked store or historical model directory was accessed.

Original traceback stderr is retained locally under LOCAL_ONLY names. The public derivative replaces the exact isolated workspace prefix with <ISOLATED_CANDIDATE_ROOT>, with no other byte edits. Original/public hashes, sizes and replacement counts are in test receipts. Test commands are recorded relative to the candidate root. Original source bytes are public repository code.

Explicit payload paths are scanned for absolute drive paths, private account markers and private-key markers before each commit. LOCAL_ONLY operation scripts, states, raw tracebacks and remote caches are excluded. Manifest and final receipt avoid self-hash cycles; final seal identity is verified in the external receipt. No cleanup or deletion is performed.

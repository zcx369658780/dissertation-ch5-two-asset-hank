# Privacy and source preservation

Only the authorized new smoke validator, supervisor and this task's necessary reports/records are published. No existing src, package initializer, historical evidence, data or production file changed. Prior25 files, historical candidate refs and STOP receipt hashes are verified unchanged.

The real source cache, local operations, exact raw stdout/stderr and network caches are LOCAL_ONLY and excluded. Public outputs replace only exact workspace/runtime path prefixes, including their JSON-escaped variants; raw/public byte counts and SHA256 plus replacement counts are preserved. Empty stderr files are genuine. No output newline conversion or numerical log alteration is applied. Public module origins truthfully refer to the redacted authenticated task cache.

The original source cache contains unchanged public Git code, not empirical data; it is not republished. No protected P3 tree, old locked store, WASM/reparse target or historical dataset directory was visited. No credentials or keys were inspected. Explicit publish paths are scanned for private absolute drive paths, local account/private-key/token markers. All LOCAL_ONLY content and this task's new contract on governance remain outside the candidate payload. No cleanup/deletion occurs.

# Joint K/L initialization sequence (design only)

## Scope and gate

This is a lowest-risk staging contract for a later, explicitly authorized scientific task.  It is based on the accepted corrected-2018 ledger and static source-audit findings only.  It selects neither a GovInv rule nor a labor-reference rule, and it is not an authorization to run a household pass, HJB/KFE, `Lt_seperate`, firm routine, root solve, outer turn, or steady state.

The accepted evidence fixes the following starting constraints: firm capital is `Kt_supply + GovInv`; productive household capital is illiquid `At`; the historical `GovInv0=Ktarget` is source-faithful but overshoots after positive private supply; and `N0` is a population proxy, not observed workplace employment.  Therefore the capital and labor correction paths must be identified separately before any joint scientific initialization.

## Dependency rule

`Lref -> Z0 -> initial prices -> optional one-pass private-K observation -> GovInv0 -> complete initial state -> separately governed controller -> outer loop`.

The arrows are one-way for initialization.  Neither late-window overshoot nor HJB/KFE convergence, boundary hits, or any objective/solver statistic may be fed backward to select `Lref`, the `At` bridge, `GovInv0`, controller damping, or price bounds.

## Minimum-risk order

First close documentary and data decisions for labor total/reference and private-capital observation; second prepare static unit/accounting tests; third, if authorized, make one receipt-producing initialization pass; fourth decide GovInv initialization; and only in a separate task consider controller compatibility and an outer trajectory.  This ordering retains causal attribution and prevents a labor-scale change from being misread as a capital-controller repair.

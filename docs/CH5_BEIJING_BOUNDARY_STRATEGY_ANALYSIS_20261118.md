## 当前离散问题的定义

采用运行副本中的净工资接口及既有原方程。记非流动资产为 a，液态资产为 b，劳动为 l，转移为 d，即时效用和漂移为

\[
u(c,l)=-\frac1c-\frac{l^6}{6},\qquad
\mu_a=\widetilde r_a(a)a+d,
\]

\[
\mu_b=r_b b+wzl+T_t-d-\chi_0|d|
-\frac{\chi_1 d^2}{2\max(a,\bar a)}-c.
\]

实际执行副本中的既定上界回报处理为

\[
\widetilde r_a(a)=r_a\left[1-0.1(a/a_{\max})^9\right].
\]

本次两个格点均为 a=10 的上界，z=1.3，净工资 w=20，因此 wz=26。源码输入 r_a=.09，在此点有效回报为 .081，非流动资产收益流为 .81。四个获选策略均满足 \(\mu_a=.81+d<0\)，对应向网格内部流动。模型金额单位为 10 万元。

原边界策略以 B、F 两个液态资产导数生成消费与劳动锚点，并加入基准劳动的 LIQUID_0 锚点。每个锚点内生成有限转移候选，再按实际漂移方向选择导数评分

\[
H_h=u(c,l)+D_a^{\operatorname{sgn}(\mu_a)}V\,\mu_a
+D_b^{\operatorname{sgn}(\mu_b)}V\,\mu_b.
\]

评分时的导数由实际漂移确定。锚点名称只记录消费与劳动的生成来源。LIQUID_0 的消费由基准劳动和零转移资源式生成，候选随后采用非零 d 时，实际 \(\mu_b\) 可以偏离零。

当前资产状态约束要求边界处漂移指向网格内侧，以既定 \(10^{-12}\) 容差核验。两个观测点的 b 均在网格内部，此处约束允许正、负液态漂移。`full_b_grid_bound=True` 表示使用整条 b 网格识别其上下边界，其对内部格点的转移速度并未给出有限上限。

## 新定位的候选覆盖缺口

第 23 轮格点 [15,19,1] 的获选策略为

| 项目 | 原值 |
| --- | --- |
| 消费劳动生成锚点 | LIQUID_B |
| 消费 c | 17.065984840615418 |
| 劳动 l | 0.6167968220101306 |
| 转移 d | −1.2344609605450219 |
| 实际液态漂移 | +0.09988432561699767 |
| 原后向导数 | 0.0034335018754994956 |
| 实际评分使用的前向导数 | 0.0032051347285323595 |

这里 \(c^{-2}\) 与 \(l^5/26\) 对应后向导数，实际正漂移下 Hamiltonian 的相关边际价值为前向导数。固定 d，并在正漂移分支内部考察连续控制，得到

\[
\frac{\partial H_h}{\partial c}
=c^{-2}-D_b^+V
=+0.0002283671469671361,
\]

\[
\frac{\partial H_h}{\partial l}
=26D_b^+V-l^5
=-0.005937545821145501.
\]

由于 c、l 均为正、b 位于内部、\(\mu_b>0\)、\(\mu_a<0\)，足够小的消费增加或劳动减少具有可行邻域，可提高当前离散 Hamiltonian。浮点复算与基于保存浮点数的有理数表达对两个导数的符号一致。

四个实际获选者中，其余三个在消费、劳动这两项一阶条件上的残差处于约 \(10^{-17}\) 或以下。格点 16 第 23 轮的前向锚点与其正漂移方向一致。因此，仅以格点 16 的锚点切换为依据强制采用后向策略，缺少连续最优性支持。

全部 98 个原候选评分逐位复算一致，四处获选者均为原有限池唯一最高分。源码和回执明确记录 `continuous_d_certified=False`、`joint_global_certified=False`。本次额外定位到有限池获选者对连续消费、劳动存在的局部改进空间。改变该空间后两格值差将如何响应，仍需新的对照证据。

## 值差反转与无界尾部

第 23 轮两格原方程之差满足

\[
(.05+.001)(V_{16}^{new}-V_{15}^{new})
=\Delta u+\Delta V^{old}/1000
+\Delta(A_bV^{new})+\Delta(A_aV^{new})+\Delta(A_zV^{new})
+\Delta\epsilon.
\]

即时效用差为 −0.004312745774611104，旧值及三项算子贡献之和为 +0.004296490104165002。两行残差最大绝对值为约 \(1.33\times10^{-15}\)。更新后的值差为 −0.00031873863615694553，对应下一轮后向导数 −0.0008651477267117092。两点所用的漂移率与本次获选策略逐项接通。

评分用上一轮 V，线性更新求解新 V。第 23 轮格点 15 的正漂移方向斜率从评分时 +0.0032051347285323595，变为更新后 −0.0008651477267117092。格点 16 的对应前向斜率从 +0.003806766030617422 降为约 +0.001884857133220809。候选评分正确与更新后液态资产单调性保持需要分别核验。

在失败点固定 c、l，沿 d 趋向负无穷，记 \(q=\chi_1/[2\max(a,\bar a)]>0\)，有

\[
\mu_b=-qd^2+O(|d|),\qquad
H_h=-qD_b^-V\,d^2+O(|d|).
\]

第 24 轮 \(D_b^-V<0\)，二次项为正，原状态约束在该内部 b、上界 a 的负转移射线上允许这种局部漂移。三条原尾部证书与此一致。其经济含义是巨额退出非流动资产时，二次调整成本最终消耗液态财富，负液态边际价值却对这种财富损失给出正向评分。

正向邻接率及每行守恒可以支撑给定策略线性系统的数值性质，沿财富维度的值函数顺序仍需额外条件。原线性系统的低残差对其自身方程有明确含义，当前证据对连续联合最优性和经济单调性的保证仍有缺口。

## 可选边界策略及含义

| 选择 | 数值含义 | 经济含义及需要决定的范围 |
| --- | --- | --- |
| 沿用现行有限 C/l 锚点池 | 候选身份、排序和原尾部停止均有现成证据，连续覆盖缺口仍存在 | 研究对象继续依赖状态和导数生成的有限动作近似，北京返回待解 |
| 原方程下联合状态约束最优化，建议优先评估 | 联合处理 c、l、d，各漂移分支、零漂移换向面和实际资产边界，并检查求解域及更新单调性 | 延续原资源约束和效用，边界候选与实质数值语义需要 Owner 采用，生产 HJB 的冻结调整另按实际方案决定 |
| 引入有限转移速度或时间步可达性上限 | 将部分无界射线改成有界控制集合，仍需处理负值差 | 引入每期资产调整速度或交易额度限制，其经济参数、单位和解释需要 Owner 决定 |
| 导数截断、值函数形状投影或强制锚点过滤 | 修改评分导数、更新结果或候选资格，需检查其对应的离散方程 | 会改变既定数值语义，截断阈值、投影准则或过滤规则需要具体研究依据 |

第一项适合原失败复现。第二项优先解决现有候选对原控制问题覆盖不足这一已经发现的问题。第三项对应新的经济约束。第四项需要核对其隐含问题定义。现有四次科学运行对上述替代选择的收敛与全局稳态表现均无实测结论。

## 建议优先评估的数学对象

对给定旧值函数，明确考虑原控制集合上的

\[
\sup_{c>0,\,l\ge0,\,d\in\mathbb R}H_h(c,l,d;V)
\quad\text{满足原资产边界的可行漂移约束}.
\]

离线定义应至少覆盖以下内容。

1. 在实际漂移符号分支内部，以同一液态边际价值 p 处理 \(c=p^{-1/2}\)、\(l=(26p)^{1/5}\) 和对应转移条件，再检查分支与边界可行性。
2. 在 \(\mu_b=0\) 处联合资源式和一侧最优性条件。内部 b 的消费方向条件要求 \(D_b^+V\le c^{-2}\le D_b^-V\)。两侧次序相反时，这个无额外活跃约束的零漂移点无法满足局部最大值条件。
3. 在 \(\mu_a=0\)、资产物理边界及成本绝对值换向处处理相应约束乘子或一侧条件。当前观测的四个获选者均为严格向 a 内部漂移。
4. 明确负液态边际价值下原连续无界控制问题的定义域。仅补足联合最优化会在已形成负斜率的点遇到同一无界问题。需要评估采用的边界最优性与整次离散更新能否保持其可解域。
5. 对满足正斜率的留存点核对最优性，对保存的负斜率失败点核对尾部判定，并核对生成元的非负邻接率、行和及离散漂移的一致性。真实运行前按实际方案处理家户冻结范围。

上述是待采用的研究对象和验算要求。本次代码仅消费留存标量做代数复算，新策略实现和结果均待后续决定及证据。

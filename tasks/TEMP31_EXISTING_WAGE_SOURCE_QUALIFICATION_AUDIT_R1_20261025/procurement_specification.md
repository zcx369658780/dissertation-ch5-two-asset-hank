# 条件性采购规格（仅供 Owner 决定）

没有采购、付款、联系卖家或下载商业数据，本任务不授予这些权限。

当前不能因有界检索缺口认定官方数据不存在或必须购买。应优先评估已找到的免费官方表和辽宁/黑龙江ZIP、湖北RAR等官方目录路线；是否允许进一步获取具体附件，由 Owner 单独决定。

若 Owner 日后明确选择采购，交付须逐项满足：

- 地理范围为31省级地区，必须有明确行政区代码/名称及版本和映射，不以行序代替ID。
- 目标观测年2018；城镇私营、城镇非私营两类别分别提供年度平均就业人员工资。不得替换成在岗职工、月工资、全口径社保缴费基数、居民工资性收入或规模以上企业分岗位工资。
- 每个目标单元须给官方原始URL、出版机构、年鉴正式书名/版次/ISBN（由实际目录证明，不预填）、表名/表号/页码、行列定位和原始页/表证据；链接存在不是可用性证明。
- 明列元/人/年或原始单位、统计总体/分母、工作地/居民地、年度平均/年末、调查方法、税前/税后和名义/不变价。未知字段保留UNKNOWN，不接受供应商自行净工资、工时/效率或就业权重换算。
- 2018观测年、发布年份、年鉴版次和修订vintage分开。后年年鉴历史列须注明修订链，不拼成伪共同快照。
- 缺失单元、原始空白和不适用必须保留；不插值、不均值填补、不用二手估算补成完整面板。
- 同时提供原始证据身份、SHA-256、整理步骤、数据字典和逐单元来源映射；真实机构/合法授权及可用于论文引用的许可须能核验。
- 未来合同应先约定少量可对照的省份/两类别证据样例、来源与口径不符的拒收/退款条件、可复核性和售后责任。这只是待协商验收条件，不是本轮索样、接洽或下单指令。
- 报价、预算、交易平台、联系人、样例获得、购买和数据采用均待 Owner 新授权。本轮没有选择供应商或采购渠道。

采购获得数据也不自动解决净工资桥、共同vintage、家庭/企业劳动单位、生产ID接线或模型接受。

# Public derivative privacy policy and actual gate

Original four NPZ archives, full vectors/CSR, raw logs, source caches, operational scripts and remote API caches remain LOCAL_ONLY. Public files contain summaries,20-bin marginals and only three positive/negative state examples per quantity.

The exact original STOP_PRIVATE_PAYLOAD assertion is evaluated without modification over every final payload file, including manifest, and over the seal file before creating each commit. Actual path-by-path verdicts and file identities are kept in LOCAL_ONLY scan receipts; the seal records payload PASS and external final receipt records final scan/readback. A failure stops publication. No private-path or numeric data is silently removed from original archives/logs.

Raw/public stdout and stderr have separate hashes and metadata-only redaction records; no numerical field changed. No credentials or key contents inspected.

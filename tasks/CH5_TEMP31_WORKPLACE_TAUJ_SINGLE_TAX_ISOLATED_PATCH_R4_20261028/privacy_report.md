# Privacy and write scope

Payloads contain only three new code files, synthetic constants and this task's public evidence. No local absolute workspace path, credential, private lock mapping, raw wage microdata, empirical dataset, WASM path or protected asset is intentionally included.

The first expected-failure traceback is a redacted derivative: only its exact private workspace prefix is replaced with <ISOLATED_CANDIDATE_ROOT>. Original raw stderr remains local, unstaged and unchanged. The public transformation record includes byte counts, original/output SHA-256 and replacement count, never the private prefix. Other test outputs are original captured bytes. No private file is uploaded to supply the missing auxiliary sources.

Only explicit payload paths are used to build Git objects; the existing work directory's untracked R3 evidence, local-only traceback and operational files are not staged or committed. The original R3 receipt/source_identity/result hashes and its branch are checked for preservation. Ten authenticated existing code files retain source bytes; new source files have no import or production wiring to household solvers.

The final stage records a bounded payload privacy scan. This is an executor review, not independent GPT privacy acceptance. No cleanup/deletion is performed; all original private evidence stays local.

# Prompt 与交接格式
更新：2026-09-07。

完整 Codex 启动 prompt 放在一个连续 Markdown 代码框中。任务细节写入已发布的 GitHub task；启动 prompt 给出仓库、任务路径、关键边界和交付要求。

交接在上下文不足、阶段更换或用户请求时进行，不因每个工程子步骤完成而强制生成。
交接只需：仓库与角色、可核验 checkpoint、当前问题、未完成任务、关键证据、下一步及不可误读的科学边界。
不把聊天转述当作已验证仓库状态。避免同时维护多份互相冲突的 CURRENT handoff。

反馈先写结论，再写改变了什么、相关验证和剩余问题。短状态可代替长 terminal 字符串；任务指定的机器 marker 仍需准确输出。

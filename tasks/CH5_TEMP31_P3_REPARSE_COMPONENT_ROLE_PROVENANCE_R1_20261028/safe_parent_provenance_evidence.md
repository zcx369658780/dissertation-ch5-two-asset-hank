# 安全父边界与有限来源证据

允许的四份旧记录在读取前按公开前候选的alias/hash对应，读取后按原字节bytes/SHA复核，再核对词法父链与核准科研根。ANCESTOR_00至02的旧reparse=false记录被复用；本轮只重新核ANCESTOR_02和03，不通过命中组件继续访问任何下级路径。

原件JSON通过指定精确路径的只读OPEN_REPARSE_POINT句柄核对对象属性后读取；拒绝将reparse或目录对象作为原件文件。没有调用链接目标解析API。输入句柄的对象属性核对是获准JSON读取的一部分，不是额外路径lstat。

安全声明资格=NO_ADMISSIBLE_MANIFEST：获准lookup和四记录中，没有明确指定处于ANCESTOR_02或更安全上层的具体小型package/build声明。实际声明读取0；没有试探任何候选文件、目录或缓存。严禁因尚余预算自行猜测声明文件。

可审阅的有限来源仅为：私有旧记录对应公开固定hash、词法父链一致性、新增非跟随元数据及原生tag类别。安装工具/时间/构建ID、实际物理链接目标、来源签名、内容安全、真实TEMP31数据/生产采用均UNKNOWN/BLOCKED。旧原始status流及六WASM内容不在本轮范围内。
